    Hover previews, click commits

    Hovering an option spotlights that search area and dims the rest of the image. The saved selection stays visible as a dashed outline, so the user can compare the two. Moving off the list returns to the selection.

    Colour key in the list

    Each option carries a swatch in the same colour as its box on the image. The user can match list entries to areas at a glance.

    Keyboard and touch

    ↑ ↓ move the preview, Enter selects, Esc closes. Touch screens have no hover, so a tap there still selects directly, which is today's behaviour.
